감전 술래잡기

전기 괴물에게 닿으면 지지직 마비!
동료에게 전력을 나눠 줘서 다시 살려 내세요.

이렇게 놀아요

  • 도망자: 술래(전기 괴물)에게 닿으면 감전 마비! 제한 시간 90초를 버티면 승리.
  • 술래: 도망자 전원을 동시에 마비시키면 승리. 처음 1.5초는 충전 중이라 못 움직여요.
  • 마비된 동료 곁에 머물면 내 전력을 나눠 줘서 부활! (전력 30 필요, 둘이 같이 하면 더 빨라요)
  • 전력은 대시에도 써요. 노란 충전 패드 위에서 빠르게 회복.
  • 절연 장갑: 감전을 1번 막고 술래를 튕겨 내요 (도망자 전용).
  • 고무 장화: 6초 동안 빨라져요. 배터리: 전력 +50.
  • 정전기 지뢰: 들고 있다가 대시하면 뒤에 설치. 밟은 상대 팀이 마비/기절!
  • 맵 4종: 변전소 마당 · 배전반 미로 · 테슬라 공장(순간이동 코일) · 번개 옥상(낙뢰 주의). 3판 2선승.
조작 — 이동: WASD/방향키 · 대시: Space/F (2인: P1 F·Space, P2 Enter·/) · 일시정지: Esc
터치 — 화면 아무 곳이나 끌어서 조이스틱, 오른쪽 아래 대시 버튼. 2인은 화면 왼쪽 P1 · 오른쪽 P2 (가로 화면 추천).
