🚗 방법 보기

  • 🚗차는 자동으로 가속해요. ◀ ▶ 버튼(←→ / AD)으로 핸들을 돌려요.
  • 🔋배터리 하나 = 배달할 전기 + 부스터 연료. 이 게임에선 그냥 달리는 데 전기가 들지 않아요(실제 전기차는 달릴 때도 배터리를 써요).
  • 🏠빨갛게 깜빡이는 정전 건물 앞의 노란 배달 구역을 지나가면 배터리 전기가 자동으로 배달돼요 → 점수!
  • 🚑긴급 요청(병원 등)은 시간이 짧지만 점수 2배. 시간이 다 되면 사라져요. 경쟁 차도 배달하니 먼저 가세요!
  • ⚡부스터(Space): 아주 빨라지지만 배터리를 빠르게 써서 배달할 전기가 줄어요.
  • 🟩초록 충전 패드와 결승선 앞 충전소 레인(오른쪽 차선)에서 충전. 천천히 지나갈수록 많이 충전!
  • 🛑브레이크(↓ / S / Shift): 감속하며 회생 제동으로 조금 충전. 브레이크+핸들 = 드리프트. 멈춘 상태에서 누르면 후진.
  • 🧱벽에 부딪히면 감속돼요.
  • 🏁3바퀴. 최종 순위 = 배달 점수 + 도착 보너스(1등 300 · 2등 200 · 3등 100).
  • 💰상금으로 차고에서 업그레이드. 2위 이내면 다음 트랙이 열려요(총 5개).
